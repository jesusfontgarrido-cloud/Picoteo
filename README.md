# Picoteo's · Web

Web de Picoteo's (comida casera para llevar) montada a partir del diseño de Figma (página "Esto es claude").

- `index.html` — Home (frame "Desktop" + "Home móvil Picoteo's").
- `carta.html` — Carta completa por secciones y formulario de contacto (segundo frame "Desktop").

HTML, CSS y JavaScript sin dependencias: basta con abrir `index.html` en el navegador o publicarlo en cualquier hosting estático (por ejemplo GitHub Pages).

Diseño responsive: escritorio fiel al frame de 1440 px (escalado proporcional hasta 900 px) y versión móvil fiel al frame de 390 px.
